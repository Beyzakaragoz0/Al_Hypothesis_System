# AI-Based Dataset Hypothesis Recommendation System

## Project Overview

This project is an AI-supported academic performance analysis and hypothesis recommendation system developed using **n8n Workflow Automation**, **HTML**, **CSS**, and **JavaScript**.

The system collects user data such as:

* Study Hours
* Absence Count
* Exam Score

and automatically generates:

* Academic Performance Analysis
* Confidence Score
* Performance Category
* AI-Based Recommendations
* Hypothesis Generation

---

## Technologies Used

* n8n Workflow Automation
* HTML5
* CSS3
* JavaScript
* Webhook Integration
* Dataset Analysis Techniques

---

## Workflow Structure

1. Webhook
2. Input Validation
3. Create Dataset
4. Data Cleaning
5. Feature Analysis
6. Generate Hypotheses
7. Confidence Score
8. AI Recommendation
9. Save Results
10. Respond to Webhook
